## "The flow tools are not here, so mods are off"

Mods are not loaded: admin policy, untrusted folder, a crash or a rollout switch. Try `/reload-plugins`, trust the folder, or ask your admin. The agent will not edit flow files by hand as a workaround, by design.

## "flow_manager.py did not start" or "gave no JSON"

Python is missing or too old. Install **Python 3.9 or newer** and make sure `python3` (Windows: `python`) runs from a terminal, then press **Continue** on the flow on the site. See [Installation](/guide/installation).

## The site shows no templates

Open the **Templates** screen, **Refresh**, then **Install**. If Refresh fails, check you can `git clone` the marketplace URL from a terminal.

## "Session closed. Press ZeremAI in a live session."

The session that the site talks to has not sent a heartbeat for 3 minutes, so the site turned its actions off. Go to a Claude Code session that is open, and press **ZeremAI ↗** above the prompt (or run `/zeremai`). The site then works with that session. If the session is open and the site still says so, run `/zeremai` and read the message: it names the last write that failed.

## "Open ZeremAI from a session to use actions."

You opened the pinned link, with no session in it. The site only shows the data. Press **ZeremAI ↗** in a session to get a link that names the session.

## A button on the site stays on "Sending…" or "Running…"

The command waits for your session. It starts within about 5 seconds when the session is idle or working. If it does not start, check that the session is open and has the flow, then press the button again. A command for another session is left alone by design.

## `/zeremai` does nothing, or the page does not open

ZeremAI opens the page with the Artifact tool, so you need a claude.ai sign-in and a surface with that tool (not print mode, not the VS Code extension). If the tool cannot open the page, ZeremAI uses the system opener and then shows the link in a message. Open the link by hand.

## Agent cannot edit a flow file

Intended. A flow's state files and findings change only through the flow script (`scripts/flow_manager.py`), and the plugin checks every call. If a call is refused or errors, read its message: it says what to do next.

## Step will not complete

It has `approvalRequired: true` and you have not approved. Open the dialog (it reopens on your next prompt) and click **Approve**, or press **Approve** on the site.

## "Flow log failed, so your prompt was not sent"

The plugin logs each prompt of a flow session before the agent sees it. A small model (Haiku) writes the details of the entry. If that call or the flow script fails, the prompt is not sent and the message says why. Send the prompt again. If it keeps failing, close the flow on the site.

## Resume lands on the wrong step

Check the truth:

```bash
cat ~/.claude/zeremai/active/<flow>/flow.json
```

Look at each step's `status` and the current-state fields. Fix status through the agent (it calls `update_step_status`), not by editing.

## A flow I finished is not in `completed/`

Completion moves the folder, so the path changes. Look in `~/.claude/zeremai/completed/`. Failed flows go to `failed/`.

## Still stuck

Open an issue: [https://github.com/HMTools/ZeremAI/issues](https://github.com/HMTools/ZeremAI/issues). Include the flow's log (remove anything private).
