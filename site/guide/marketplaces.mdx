Templates are distributed through **git-backed marketplaces**, not bundled with the plugin.

## Why

- **Versioned**: track a branch or tag.
- **Team sharing**: host private templates in your own repo.
- **Multiple sources**: combine official and custom repos.
- **Per-template install**: install only what you need.
- **Update detection**: see which installed templates have newer versions.
- **Independent updates**: update templates without updating the plugin.

## Create your own

A marketplace is a git repository with `templates/flows/<category>/<template>/<template>.json` in it, and a subfolder for each step. In a Claude Code session, run:

```
/zeremai:create-marketplace A shared library of review flows for the payments team
```

The skill plans the folder and shows it on one page: the file tree, how the Templates screen of the site will list it, each step, and where you want the repository to live. Nothing is written until you press **Approve**. It then creates the folder, runs `git init` on branch `main`, makes the first commit, and checks the result.

Everything that leaves your machine or changes your config asks first and shows the exact command: adding the marketplace to `marketplaces.json` (with the local path, so you can install from it at once), creating a GitHub or Azure DevOps repository, and pushing to a new or an empty existing repository. It never forces a push. Then add templates with [`/zeremai:create-template`](/authoring/templates).

To check a marketplace yourself, run the check script of the plugin:

```bash
python3 <plugin>/scripts/check_template.py --marketplace <folder>
```

It checks every template, that each folder name and category match the JSON, that template ids are unique, and that sub-flows point to templates in the repository.

## Manage from the site

Open `/zeremai` → **Templates**. The list is grouped by marketplace.

| Action | Effect |
|---|---|
| Refresh | Fetch the latest catalogs from all enabled marketplaces |
| Install | Copy a template from the marketplace cache. On an installed template with a newer commit it updates it. |
| Remove | Delete an installed template. The site asks first. |

The site does not add or edit the marketplaces themselves. To add one, change its git address, branch or priority, switch it off, or remove it, edit [the config file](#config-file) below. Then press **Refresh**. Removing a marketplace deletes its cache, not the templates you already installed.

## Config file

`~/.claude/zeremai/config/marketplaces.json`:

```json
{
  "marketplaces": [
    {
      "name": "official",
      "url": "https://github.com/HMTools/ZeremAI-marketplace.git",
      "branch": "main",
      "enabled": true,
      "priority": 100
    }
  ],
  "settings": {
    "autoRefreshOnStale": false,
    "staleDurationMinutes": 1440
  }
}
```

| Field | Meaning |
|---|---|
| `name` | Short identifier |
| `url` | Git clone URL |
| `branch` | Branch to track (default `main`) |
| `enabled` | Skip the marketplace when `false` |
| `priority` | Lower number = higher priority |
| `autoRefreshOnStale` / `staleDurationMinutes` | Refresh automatically once the cache is older than this |

## Private marketplaces

Use any git URL your machine can already clone (SSH, or HTTPS with your credential helper). ZeremAI runs plain `git`, so it needs no extra credentials of its own.
