## What is on the screen

1. **Refresh marketplaces** fetches the latest catalog of every enabled marketplace.
2. **Search templates** filters the list.
3. **Installed** lists what you have. Each row shows the category, the marketplace, the version, the number of fields, and notes such as `edited by you` or `update ready`. A template with an update shows `v1.2.0 → v1.3.0` and a **What is new** list from its `changelog.json`. Updates sit first in the list.
4. **One group for each marketplace**, with the time of its last refresh. Templates you have not installed have an **Install** button.

## The buttons

| Button | What it does |
|---|---|
| **Install** | Copies the template from the marketplace cache. |
| **Update** | Shown when the marketplace has a newer commit and you did not edit the template. It runs at once. |
| **Update…** | Shown instead of **Update** on a template you edited. It asks first and says `This erases your change.` Press **Yes, update** or **Keep it**. |
| **View** | Opens the template on one page. Runs [`/zeremai:view-template`](/commands/view-template). |
| **Edit** | Opens a box, **What should change?**. Write the change and press **Ask Claude**. Claude drafts it, and you approve before it saves. Runs [`/zeremai:edit-template`](/commands/edit-template). |
| **Send as PR** | Shown on a template you edited. Sends the change to its marketplace as a pull request. See [Edit and send a template](/authoring/edit-and-send). |
| **Remove** | Deletes the installed copy. It asks first. |

To add, edit, switch off or remove a marketplace, open [Marketplaces](/ui/marketplaces).

## Versions and update notices

A template has its own version in `metadata.version` and a `changelog.json` in its folder (`{"versions": [{"version", "date", "changes": [...]}]}`, newest first). An update shows only when the marketplace copy has a higher version than the one you installed. A template you installed before versions existed counts as `0.0.0`, so it shows one update.

At the start of each session ZeremAI pulls the marketplaces and says once, in the terminal, when installed templates have updates. The site shows a banner with **Review**, **Later** and **Skip these versions**, and a count on the **Templates** tab. **Review** opens this screen. **Later** hides the banner until you open the site again.
