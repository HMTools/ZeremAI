## What is on the screen

1. **Refresh marketplaces** fetches the latest catalog of every enabled marketplace.
2. **Search templates** filters the list.
3. **Installed** lists what you have. Each row shows the category, the marketplace, the number of fields, and notes such as `edited by you` or `update ready`.
4. **One group for each marketplace**, with the time of its last refresh. Templates you have not installed have an **Install** button.

## The buttons

| Button | What it does |
|---|---|
| **Install** | Copies the template from the marketplace cache. |
| **Update…** | Shown when the marketplace has a newer commit. It asks first, because it erases an edit you made. |
| **View** | Opens the template on one page. Runs [`/zeremai:view-template`](/commands/view-template). |
| **Edit** | Changes the template from your description. Runs [`/zeremai:edit-template`](/commands/edit-template). |
| **Send as PR** | Shown on a template you edited. Sends the change to its marketplace as a pull request. See [Edit and send a template](/authoring/edit-and-send). |
| **Remove** | Deletes the installed copy. It asks first. |

The site does not add, edit, switch off or remove a marketplace itself. For that, edit `marketplaces.json`. See [Marketplaces](/guide/marketplaces#config-file).
